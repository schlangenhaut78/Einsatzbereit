# Einsatzbereit – Kompetenzmodell 4.0 (Entwurf)

Stand: 2026-11-02 · Status: **freigegeben 2026-11-02**
Löst den Widerspruch Kompetenzmodell 3.0 ↔ Fähigkeitsbibliothek 1.0.

## Prinzip: zwei Ebenen
- **8 Hauptkompetenzen** – das sieht der User (einfach, wiedererkennbar).
- **Unterkompetenzen** – intern für Berechnung; nur in Detailansicht sichtbar.
- Fähigkeiten werden auf **Unterkompetenzen** gewichtet; der Wert der Hauptkompetenz ergibt sich daraus.

## Struktur
| Hauptkompetenz | Unterkompetenzen | Typische Datenquelle |
|---|---|---|
| **Bewegung** | Bewegungsqualität · Bewegungsfähigkeit (Bodenwechsel, Kriechen, Bücken) · Gleichgewicht | Selbsttests (Einbeinstand, Aufstehen vom Boden), Feedback |
| **Ausdauer** | Kurz-/Mittelzeitausdauer (3–30 min – z. B. Feuerwehr-Atemschutz, Kisten tragen) · Langzeitausdauer (> 30 min bis Stunden – z. B. THW, Wandern) | Schritte, Training, Puls, Treppentest, 6-Min-Gehtest |
| **Kraft** | Funktionskraft (Heben/Tragen) · Kraftausdauer · Schnellkraft · Rumpfstabilität · Griffkraft | Selbsttests (Sit-to-Stand, Tragetest), Trainingsprotokoll |
| **Mobilität** | Allgemeine Beweglichkeit · Schulterbeweglichkeit · Hüft-/Rückenbeweglichkeit | Selbsttests (Reichweite, Überkopf), Feedback |
| **Regeneration** | Schlaf · Erholung (Ruhepuls, HRV, Pulserholung) | Tracker über Health Connect |
| **Ernährung** | Flüssigkeit · Protein · Gemüse/Obst | kurze Selbstangabe (z. B. 3 Antippen/Tag) |
| **Selbststeuerung** | Durchhalten · Pausen einhalten · Routine | Feedback, Einhaltung von Pausen/Plänen |
| **Entwicklungsfähigkeit** | Konstanz (Trainingsregelmäßigkeit) · Anpassung (Fortschritt pro Woche) | automatisch aus Verlauf |

## Zuordnung der alten Begriffe (Fähigkeitsbibliothek 1.0)
| Alter Begriff | Neu |
|---|---|
| Funktionskraft | Kraft › Funktionskraft |
| Belastungsfähigkeit | entfällt als Begriff → Ausdauer › Kurz-/Mittelzeitausdauer (Feuerwehr, DLRG, Kisten) bzw. › Langzeitausdauer (THW, Stadtradeln, Mehrtagestour) |
| Bewegungsqualität | Bewegung › Bewegungsqualität |
| Bewegungsfähigkeit | Bewegung › Bewegungsfähigkeit |
| Gleichgewicht | Bewegung › Gleichgewicht |
| Rumpfstabilität | Kraft › Rumpfstabilität |
| Schulterbeweglichkeit | Mobilität › Schulterbeweglichkeit |
| Ausdauer | Ausdauer › Langzeitausdauer (Treppen: Kurz-/Mittelzeit) |
| Kraft | Kraft › Kraftausdauer |
| Mobilität | Mobilität › Allgemeine Beweglichkeit |
| Regeneration | Regeneration (beide Unterkompetenzen) |

Die Gewichtungen der Fähigkeitsbibliothek bleiben unverändert, nur die Begriffe werden zugeordnet.

## Ernährung (löst offenen Punkt 5)
Ernährung ist **Hauptkompetenz**. Das Ernährungsregelwerk beschreibt, wie sie erfasst (minimal) und welche Tipps gegeben werden. Keine Kalorienzählerei.

## Begriffsklärung (Fachquellen)
- **Ausdauer** = Ermüdungswiderstandsfähigkeit: eine Leistung möglichst lange durchhalten. Einteilung nach Dauer: Kurzzeit 3–10 min, Mittelzeit 10–30 min, Langzeit > 30 min (Spektrum Lexikon der Ernährung).
- **Belastung** (äußere: Dauer, Gewicht, Wiederholungen) vs. **Beanspruchung** (innere: Puls, Borg-Wert) (Gesundheits-Lexikon, Trainingswissenschaft).
- **Belastbarkeit** = individuelle Toleranzgrenze gegenüber Belastung; in der Trainingslehre kein eigenständiger Fähigkeitsbegriff, sondern Ergebnis von Ausdauer, Kraft und Regeneration. → In Einsatzbereit **keine Kompetenz**, sondern das, was Fähigkeiten/Profile ausdrücken.
- **Belastungsdauer** und **Belastungsdichte** (Verhältnis Belastung : Erholung, z. B. THW 6 h : 2 h) sind **Belastungsparameter** – sie beschreiben Anforderungen/Training, nicht Kompetenzen.
