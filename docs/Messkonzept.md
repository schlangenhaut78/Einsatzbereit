# Einsatzbereit – Messkonzept Kompetenzen (Entwurf)

Stand: 2026-11-02 · Status: **freigegeben 2026-11-02**

## 1. Grundsätze
1. **Persönlicher Ausgangswert statt Normtabelle.** Gemessen wird Entwicklung gegenüber dem eigenen Start und Abstand zum eigenen Zielkriterium. Normwerte (Alter/Geschlecht) nur intern für Plausibilität und Sicherheit. (Entwicklung statt Bewertung.)
2. **Zielerreichung entscheidet der Zieltest**, nicht ein berechneter Wert. Berechnete Kompetenz-/Fähigkeitswerte dienen nur für Prognose und Wahl des nächsten Schritts.
3. **Wenig Aufwand:** Einstiegs-Check und Wiederholungstests max. ca. 5 min, max. 2–3 Tests, nur die für das Hauptziel relevanten.
4. **Anzeige einfach:** User sieht Fortschritt zum Ziel und aktuelle Etappe. Kompetenzen als einfache Balken (5 Stufen) in der Detailansicht.

## 2. Datenquellen und Rangfolge
| Rang | Quelle | Aussage |
|---|---|---|
| 1 | Selbsttest / Zieltest | direkteste Messung |
| 2 | Trainingsprotokoll (Einheiten, Last, Wiederholungen) | Entwicklung zwischen Tests |
| 3 | Gerätedaten (Health Connect) | v. a. Regeneration, Aktivität |
| 4 | Feedback (Borg, Beschwerden) | Beanspruchung, Sicherheit |

Jeder Wert hat ein **Alter**: Tests älter als ca. 4 Wochen verlieren Gewicht → App schlägt Wiederholung vor.

## 3. Leittests je Unterkompetenz (Vorschlag)
| Hauptkompetenz › Unterkompetenz | Leittest / Datengrundlage |
|---|---|
| Bewegung › Bewegungsfähigkeit | Aufstehen vom Boden (Zeit, Hilfe ja/nein) |
| Bewegung › Gleichgewicht | Einbeinstand (Sekunden je Bein) |
| Bewegung › Bewegungsqualität | Selbsteinschätzung nach Video/Bild-Anleitung |
| Ausdauer › Kurz-/Mittelzeit | Treppentest (Stockwerke/Zeit, Puls, Borg) |
| Ausdauer › Langzeit | 6-Minuten-Gehtest (Strecke) + aktive Minuten/Woche |
| Kraft › Funktionskraft | Tragetest (Last × Strecke, z. B. Kisten/Kanister) |
| Kraft › Kraftausdauer | 30-Sekunden-Sit-to-Stand (Wiederholungen) |
| Kraft › Oberkörper/Schnellkraft | Liegestütz-Stufe (Wand / Knie / voll) |
| Kraft › Rumpfstabilität | Unterarmstütz (Sekunden) |
| Mobilität › Schulter | Hände hinter dem Rücken (Abstand) / Überkopf-Reichweite |
| Mobilität › Hüfte/Rücken | Finger-Boden-Abstand / Schuhe-binden-Test |
| Regeneration › Erholung | Ruhepuls 7-Tage-Mittel vs. persönlicher Normalwert; HRV falls verfügbar |
| Regeneration › Schlaf | Schlafdauer/-regelmäßigkeit (Tracker) oder Selbstangabe |
| Ernährung | täglich 3 Antippen (genug getrunken? Eiweiß? Gemüse/Obst?) → 7-Tage-Quote |
| Selbststeuerung | Einhaltung geplanter Einheiten und Pausen |
| Entwicklungsfähigkeit | Konstanz (Anteil absolvierter Einheiten), Fortschrittstrend |

Sicherheit bei allen Tests: Abbruch bei Borg ≥ 8, jedem Alarmsymptom (Symptom-Ampel) oder Schmerz.

## 4. Berechnung (vereinfacht)
- Unterkompetenzwert 0–100 = Position zwischen persönlichem Ausgangswert und Zielniveau.
- Hauptkompetenz = Mittel ihrer Unterkompetenzen (für Anzeige).
- Fähigkeitswert = Σ (Gewicht × Unterkompetenzwert) laut Fähigkeitsbibliothek.
- **Coach-Priorität** = Unterkompetenz mit dem größten gewichteten Rückstand für das Hauptziel → daraus der nächste Schritt.

## 5. Rhythmus
- Einstieg: Gesundheitscheck → 2–3 Leittests.
- Wiederholung: alle 2–4 Wochen (App erinnert), bzw. vor Etappenwechsel.
- Gerätedaten: laufend automatisch.
